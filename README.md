## Hypothesis Testing

**Null Hypothesis (H₀):**
There is no significant difference in average order value between male and female customers.

**Alternative Hypothesis (H₁):**
There is a significant difference in average order value between male and female customers.

### Statistical Test

Independent Two-Sample T-Test

### Results

- T-Statistic: **0.682**
- P-Value: **0.495389**

### Conclusion

Since the p-value is greater than 0.05, the null hypothesis is not rejected.

The analysis indicates that customer gender does not significantly influence the average order value.
